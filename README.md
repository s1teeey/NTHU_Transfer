## 改文字

在 Google 試算表「寒轉分享」分頁的「修改後」欄填字，重新整理網頁就會更新。跟推甄分享是同一份試算表。

- `【文字】` 會變螢光筆
- 儲存格換行就是網頁換行
- 試算表要開「知道連結的人可以檢視」
- 重新匯入 `content.csv` 會清掉已經填的字
